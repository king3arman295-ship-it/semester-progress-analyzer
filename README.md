# Semester Analyzer
Overview (up/down verdict, trend, subjects), Marks entry, Planner (deadlines + study log), Goals (what you need in the final), Settings (weights, backup).
Data lives in your browser (localStorage).

    npm install && npm run dev

Deploy: push to GitHub, import in Vercel (Vite is auto-detected), Deploy.
Structure: src/lib (logic + storage + demo), src/components (one file per page), src/styles.css.
